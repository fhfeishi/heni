## 技术与安全边界

- App 组合根；UI → feature/workflow → typed port → Tauri → Rust/SQLite。无新增全局 store。
- Rust 唯一队列事实来源，视频/音频走 HybridEngine 同一会话；前端不能自治并行播放。
- 视频监听仅 127.0.0.1，随机令牌/epoch 资源、Range 读取；旧约 20 秒停顿截图属于被替换
  的旧候选，不是当前流式版本的合格证据。保留同一个 video 元素穿过视图/Mini 切换。
- 背景显露 0–100 已实现；不要只改 slider max。100–300 需 Rust/TS/恢复测试及非盲点处理。
- 工作树含大量既有未跟踪文件，先检查，不提交、不清理、不覆盖他人改动。
- 构建前查询 heni-desktop 进程；不得强杀用户播放器以覆盖 exe。正式曲库和配色不用于破坏性 QA。
- 电脑操作服务最近两次报 program not found，不能假装取得实机截图；不要写自制 Windows 自动化绕过。
