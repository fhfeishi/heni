# 038 · 材质偏好与预览草稿

入口：`contracts/settings.ts`、`GlassControl.tsx`、`shell/glass.ts`、`App.tsx`。

`GlassSettings` 只含有限材质 material 和 0–100 整数 transparency。Rust 把这一组作为 ui.glass 原子写入现有设置表。旧设置没有该字段时使用柔雾/35；部分设置更新不注入 glass，因此换主题不重置材质。

App 保存一份可空草稿：显示值为 draft ?? saved。滑动和选择预设只改草稿，经 CSS 变量即时投影到四个界面表面；成功保存后清掉草稿，失败保留，取消退回已提交值。背景图片强度仍是单独设置，不在本切片改变其历史含义。

初始映射是三档 blur 4/16/28px，通透度映射表面底色 94% 至 40%。它不设置整个组件的 opacity，文字保持实色。无 backdrop-filter 支持时使用实体表面回退。这些数值用于实机调校，不代表对比度或性能已验收。

预设同时给出默认通透度，手动调透明度保留所选材质；恢复默认只生成草稿，仍需保存，不偷偷写库。新增存储字段不包含图片正文，也不需要新增迁移表。

练习：在 App 回归中调整通透度后切换主题，断言 glass CSS 变量保持草稿值，而 update 只提交 themeId；运行 `pnpm test`。再人工观察亮图下的文字与焦点，不能只靠 CSS 值测试判断是否好看。
