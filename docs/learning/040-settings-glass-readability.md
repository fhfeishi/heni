# 040 · 玻璃层次与设置可读性

入口：`src/styles/shell.css` 的 `.preferences-control__panel` 与 `.preferences-control fieldset`。

玻璃变量可以统一风格，但不意味着每一层必须同样透明。顶栏、侧栏是低密度的环境层；设置面板包含密集文字、滑杆和按钮，需要更强的局部底色。最初尝试 94% 覆盖率，真实窗口仍能看见舞台标题，因此设置面板最终使用不透明的主题 surface，不再套用外壳的玻璃背景。没有对整个面板设置 opacity，因此文字本身不被淡化。

双栏布局中，右侧 fieldset 被拉到与左侧等高。其内部也是 grid，默认的内容分配会把选项之间的距离拉大。`align-content: start` 让内容从顶部紧凑排列，不需要用固定高度抵消问题。滚动条使用主题强调色和透明轨道，避免系统白色轨道成为新的视觉边框。

取舍：密集操作区域优先可读性，不把“通透”机械地套用到所有表面。CSS 回归要用真实窗口检查；单元测试通过不能证明透字、间距和滚动条已经正确。

练习：在开发预览里临时去掉 fieldset 的 `align-content: start`，对比左右栏高度不一致时的选项间距，然后恢复。解释为什么仅调整 gap 不能解决多余空间的分配。
