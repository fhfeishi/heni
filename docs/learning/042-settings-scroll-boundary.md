# 042 · 把滚动边界放在内容上

入口：`src/features/settings/PreferencesControl.tsx` 与 `src/styles/shell.css`。

之前整个设置面板滚动，标题与关闭按钮会一起离开视口。现在面板分成两个网格行：标题占自然高度，正文使用 `minmax(0, 1fr)`，由正文独立承担 overflow。正文的 `min-height: 0` 允许其在有限高度里收缩，关闭按钮始终位于滚动容器之外。不需要监听 scroll 或保存滚动位置的 React 状态。

扫描设置原来与较长的场景控制并排，使短列留下大块空白。现在按外观、扫描的顺序纵向排列，长说明和滑杆使用完整宽度。仍保留原有 fieldset/legend 分组，不为布局增加页面路由或页签状态。

关闭操作只收起 details，不卸载正文，也不等同于取消外观预览。新增测试覆盖关闭焦点、正文与关闭按钮的结构边界、重新打开后的草稿保留，并验证关闭不会写入设置。

取舍：结构测试能避免以后把关闭按钮重新放进滚动区，但不能证明真实窗口没有裁切；仍须检查窄窗、正文底部及键盘导航。

练习：给测试中的外观输入输入新值，关闭并重新打开，确认值保留；然后尝试把正文条件渲染为仅打开时存在，观察为什么这会改变草稿生命周期。
