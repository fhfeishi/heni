# 043 · 新效果不应悄悄改变旧设置

入口：`src/features/shell/sceneryPresentation.ts`、`src/features/scenery/SceneryRevealControl.tsx`、`src/app/App.tsx`、`src/contracts/settings.ts`、`src-tauri/src/settings/mod.rs`。

原有图片浓度同时参与图片和遮罩计算。直接改映射会让用户保存的 100% 在升级后突然变样，因此新增独立 sceneryReveal，旧库缺少键时原生返回 0，旧前端快照缺字段时应用也使用 0。写入沿用部分更新，修改主题不补写显露值。

显露 0 保留原来的图片处理。显露 100 时，舞台图片不再附加全幅暗幕、色调遮罩、模糊或降饱和；列表仍保留遮罩与适量模糊。图片浓度依旧相乘，所以浓度 0 仍然不显示图片。舞台控件局部衬底、玻璃表面及文字不透明度不由这个滑杆修改。

状态流：已保存值 → 本地草稿 → CSS 变量预览；保存成功才清除草稿，保存失败保留可重试，取消回到已保存值。恢复原有遮罩也是草稿，需保存才持久化。没有增加数据库表、依赖或图片解码。

映射使用纯函数，测试覆盖旧值、极值、列表保护及非法输入回退；应用测试覆盖预览不写库、取消、失败重试和浓度隔离。原生测试覆盖默认、重开读回、非法值、损坏存储和事务回滚。

练习：把显露设置为 100、图片浓度设置为 0，解释为什么背景仍为主题底色；再比较同一张图片在舞台和列表的 CSS 变量。亮图是否可读仍须实机检查，不能从函数测试推断。
