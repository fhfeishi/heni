# 044 · 边缘玻璃要兼顾鼠标与键盘

入口：`src/styles/edge-glass.css`、`src/features/shell/AppFrame.tsx`。

中央内容使用一整块主玻璃，工具面板沿用同组材质变量。支持悬停的细指针设备上，顶部、左侧与底部工具面板沿边缘收起，留下可命中的边缘；悬停、焦点进入、设置或模式菜单打开时保持展开。没有监听每一帧鼠标移动，也没有添加播放状态或复制一份控件。

AppFrame 只新增 panelsPinned 本地布尔值，用于切回常驻布局。图钉有名称和 aria-pressed；此值目前仅在本次应用会话保持，不写入数据库。触摸/粗指针使用常驻布局，减少动态时移除位移动画。Mini 不使用自动边缘布局。

取舍：不能用 display:none 隐藏工具栏，否则键盘无法进入。通过 focus-within 展开，键盘仍可访问真实控件；有菜单打开时通过 details[open] 保持面板，不让用户移动鼠标进菜单时整栏消失。

测试覆盖固定切换不写外观设置；组件测试无法证明悬停命中区、层叠与动画正确，必须用 Windows 实机检查。背景 100–300 的遮盖段是后续独立切片，此处不改变当前 0–100 参数。

练习：用 Tab 进入收起的顶栏，再用图钉固定；检查 aria-pressed 与布局数据属性变化。说明为什么鼠标离开后仍有焦点时保持展开是有意设计，而不是悬停失灵。
