# 046 · 切换入口与玻璃层级

入口：`ListeningViewSwitch.tsx`、`App.tsx`、`styles/edge-glass.css`。

切换组件只接收当前是否为舞台及两个回调，不持有第二份导航状态。App 仍负责返回之前的浏览页与保留列表上下文。图标配“歌曲/舞台”两个短标签，aria-label 保留“播放舞台”，方向键/Home/End 将焦点与选择同步；不增加没有必要的侧面板或手势识别器。

背景不协调的原因之一是多层重复模糊。图片已有处理，中央主玻璃现在只使用共享模糊的四分之一，底色比例也由原先共享值的 45% 调为 25%；边缘工具玻璃保持原材质参数，形成层次。数字是本轮起始值，不是实机验收结果；无滤镜环境仍保留实体回退。

练习：在切换到歌单后进入舞台，再用“歌曲”返回，确认回到之前浏览页。说明为什么把 browseView 放进切换组件本地状态会导致职责重复。
