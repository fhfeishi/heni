# 2D 卡通应用图标四稿对照设计

## 目标

以 `output/imagegen/snorlax-headphones-full-body/01-plush-3d.png` 为结构参考，重新绘制四张 1024×1024 的 2D 卡通应用图标预览。四张稿件组成“两种画风 × 两种动作”的 2×2 对照，本轮仍不替换任何平台的正式应用图标。

## 参考图的使用范围

- 保留参考图的圆胖坐姿、小头大肚皮比例、尖耳、闭眼微笑、完整头戴式耳机，以及用户喜欢的手脚爪子结构。
- 手爪保留短圆轮廓和每只三枚浅奶油色小爪尖。
- 双脚保留厚实外形、棕色椭圆脚掌和每只三枚浅奶油色脚趾爪。
- 不保留参考图的真实毛绒纤维、写实材质、强烈体积光、塑料高光或摄影棚渲染感。
- 参考图只作为角色结构、比例和爪子造型的输入，不要求逐像素复刻。

## 共同角色与构图

- 角色正面慵懒坐着，圆胖身体和暖奶油色大肚皮是画面主体。
- 头部保持参考图的小头比例，不得放大；包括耳朵在内的头部高度不超过完整角色高度约 34%。
- 两只尖耳完整露出，耳机头梁从耳朵后方或上方形成清楚弧线。
- 双腿向左右下方自然伸开，两只脚和全部脚趾爪完整显示，不能裁切。
- 身体为暗青蓝绿色，脸部与腹部为暖奶油色，脚掌为暖棕色。
- 耳罩和头梁局部保留青蓝到紫色的柔和发光，但光效采用 2D 图形表达，不能形成写实霓虹摄影效果。
- 深蓝色简洁背景，允许极轻微的扁平渐变或纸张质感，不出现地面、森林、家具、食物或其他叙事元素。
- 角色占画面约 78%–82%，耳机、耳朵、爪子和双脚四周保留应用图标安全留白。

## 两种动作

### 双爪放在肚皮上

- 两只手爪分别自然搭在大肚皮上方左右两侧，手臂松弛下垂。
- 每只手的三枚小爪尖清楚露出，朝向腹部但不能刺入或抓皱腹部。
- 双爪不能合并、交叉、遮住脸或覆盖大面积腹部。

### 双爪轻轻扶住耳机

- 两只手爪抬到两侧耳罩，指向对称但姿态自然，像轻轻调整或感受音乐。
- 每只手的三枚小爪尖轻贴耳罩外缘，不能穿过耳罩、遮住耳朵或变成用力抓握。
- 肩膀和手臂保持下沉松弛，继续呈现闭眼、慵懒、沉浸音乐的状态。
- 双手离开腹部后，大肚皮轮廓必须保持完整清楚。

## 两种画风

### 半扁平赛璐璐

- 清晰、圆润、稳定的深青色外轮廓，大面积纯净色块。
- 每个区域仅使用一层基础色和至多一层柔和阴影；允许少量高光，但不使用真实材质反射。
- 轮廓、脸部、爪子、脚掌和耳机在 64×64 下仍清楚，整体像完成度高的 2D 动画应用图标。
- 无毛发纹理、无 3D 建模感、无摄影级体积光、无复杂渐变。

### 手绘绘本

- 柔和手绘线条、轻微不规则边缘和克制的水粉或彩铅纸张颗粒。
- 色块仍以平面为主，只用极轻的手绘明暗表现圆胖体积。
- 气质温柔、可爱、安静、慵懒，不能变成写实绘画或细节繁杂的插画场景。
- 纸张纹理不能影响小尺寸下的眼睛、爪子、脚掌和耳机识别。

## 质量策略

- 使用内置图像生成模式，每张图单独生成，参考图作为结构与爪子造型参考。
- 四张图共享角色比例、配色、耳机造型和背景约束，只改变画风与手爪动作。
- 每张生成后分别检查 2D 程度、头身比例、手爪与脚爪数量、手势、耳机结构、肢体完整性和小尺寸识别。
- 某张失败时只针对该张的单一问题重新生成，不额外堆积候选数量。
- 新稿写入独立 `v3` 目录，不覆盖先前的 3D 与小头身预览。

## 验收标准

- 恰好交付四张有效的 1024×1024 PNG，并按 2×2 矩阵清楚标注。
- 四张均为明确的 2D 卡通，不出现明显毛绒、塑料、软陶或写实 3D 渲染质感。
- 四张的角色头身比例、身体轮廓、配色、耳机和脚部结构保持一致。
- 01 与 03 的双爪分别自然搭在腹部；02 与 04 的双爪分别轻扶两侧耳罩。
- 每张都显示两只完整尖耳、两只手爪、两条腿、两只完整脚和一副连贯耳机。
- 每只手和每只脚均有三枚可辨认的小爪尖；不得出现额外、缺失、合并或畸形爪子。
- 无文字、无水印、无额外角色、无复杂场景、无裁切肢体、无畸形耳机。
- HTML 对比页只展示这四张新稿，用户选定后再进入最终图标制作。
