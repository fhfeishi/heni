# 2D 卡通应用图标四稿对照设计

## 目标

以 `output/imagegen/snorlax-headphones-full-body/01-plush-3d.png` 为结构参考，重新绘制四张 1024×1024 的 2D 卡通应用图标预览。四张稿件组成“两种画风 × 两种动作”的 2×2 对照，本轮仍不替换任何平台的正式应用图标。

## 参考图的使用范围

- 保留参考图的圆胖坐姿、小头大肚皮比例、尖耳、闭眼微笑、完整头戴式耳机，以及用户喜欢的手脚爪子结构。
- 手爪保留短圆轮廓和每只三枚浅奶油色小爪尖。
- 双脚保留厚实外形、棕色椭圆脚掌和每只三枚浅奶油色脚趾爪。
- 不保留参考图的真实毛绒纤维、写实材质、强烈体积光、塑料高光或摄影棚渲染感。
- 参考图只用于提炼角色结构、比例和爪子造型；生成时不直接传入该图，避免输出过度贴近参考外形。

## 共同角色与构图

- 角色身体保持稳定的正面慵懒坐姿，头部向画面右侧自然歪约 12°–15°；圆胖身体和暖奶油色大肚皮是画面主体。
- 头部保持参考图的小头比例，不得放大；包括耳朵在内的头部高度不超过完整角色高度约 34%。
- 两只尖耳完整露出，耳机头梁从耳朵后方或上方形成清楚弧线。
- 双腿向左右下方自然伸开，两只脚和全部脚趾爪完整显示，不能裁切。
- 身体采用低饱和的深藏青蓝或深蓝灰，不能发浅、发白或偏亮青绿；脸部与腹部采用偏黄的暖奶油色，爪尖为柔和象牙白，脚掌为暖棕色，外轮廓使用更深的海军蓝而不是纯黑。
- 角色没有猫科条纹、斑点或其他装饰花纹；脸颊、手臂和身体侧面只能使用大面积同色系轻阴影，不能画成条纹。
- 奶油色脸块采用完整、圆润的椭圆或软圆角形状，不形成尖锐额头分界；脸块、闭眼弧线、小鼻子和微笑都随头部一起倾斜。
- 耳罩采用中等尺寸的完整椭圆结构，主体为哑光深靛蓝；不能大到挤脸，也不能小到像两个分离模块。
- 耳机随头部倾斜形成自然高低差：靠近画面右侧的低侧耳罩更完整、略大，远侧耳罩略高、略靠后，但两侧都必须清楚可辨。
- 头梁是一条连续、粗细适中的斜弧线，位于尖耳后方；耳罩外缘只保留青蓝到紫色的单层细窄柔光，不能形成双层光圈或笨重发光圆环。
- 深蓝色简洁背景，允许极轻微的扁平渐变或纸张质感，不出现地面、森林、家具、食物或其他叙事元素。
- 角色整体相对旧稿下移约 3%，占画面约 78%–82%；头顶增加少量留白，耳机、耳朵、爪子和双脚四周保留应用图标安全留白。

## 两种动作

### 双爪放在肚皮上

- 两只手爪分别自然搭在大肚皮上方左右两侧，手臂松弛下垂。
- 手臂从肩部顺势下落，手腕贴合肚皮圆弧，双爪只承受自身重量般轻轻搁着；左右允许极轻微的不对称，以避免摆拍感。
- 每只手的三枚小爪尖清楚露出，朝向腹部但不能刺入或抓皱腹部。
- 双爪不能僵硬摊开、用力抓握、悬浮、合并、交叉、遮住脸或覆盖大面积腹部。

### 单爪轻扶耳机，另一爪留在肚皮上

- 靠近画面右侧低侧耳罩的手爪抬起，三枚小爪尖轻贴耳罩外侧下缘，不能穿过耳罩、遮住尖耳、盖住主要发光轮廓或变成用力抓握。
- 另一只手爪继续自然搭在大肚皮上，手腕顺着腹部弧线，三枚爪尖清楚可见。
- 抬起一侧的肩膀、肘部和手臂仍保持较低、下沉和松弛，像闭眼歪头感受音乐，而不是调整设备或摆拍。
- 大肚皮轮廓保持完整清楚，单爪动作与歪头方向形成柔和的对角线。

## 两种画风

### 半扁平赛璐璐

- 清晰、圆润、稳定的深青色外轮廓，大面积纯净色块。
- 每个区域仅使用一层基础色和至多一层柔和阴影；允许少量高光，但不使用真实材质反射。
- 轮廓、脸部、爪子、脚掌和耳机在 64×64 下仍清楚，整体像完成度高的 2D 动画应用图标。
- 无毛发纹理、无 3D 建模感、无摄影级体积光、无复杂渐变。

### 手绘绘本

- 柔和手绘线条、轻微不规则边缘和克制的水粉或彩铅纸张颗粒。
- 色块仍以平面为主，只用极轻的手绘明暗表现圆胖体积。
- 气质温柔、可爱、安静、慵懒，不能变成写实绘画或细节繁杂的插画场景。
- 纸张纹理不能影响小尺寸下的眼睛、爪子、脚掌和耳机识别。

## 质量策略

- 使用内置图像生成模式，每张图单独生成，参考图作为结构与爪子造型参考。
- 四张图共享角色比例、配色、耳机造型和背景约束，只改变画风与手爪动作。
- 每张生成后分别检查 2D 程度、头身比例、手爪与脚爪数量、手势、耳机结构、肢体完整性和小尺寸识别。
- 某张失败时只针对该张的单一问题重新生成，不额外堆积候选数量。
- 已生成的 v3 与 v4 预览作为拒绝稿或备份保留；按深藏青蓝毛色、无花纹、歪头和单爪扶耳机构图生成的四张稿写入独立 `v5` 目录，不覆盖任何旧稿。

## 验收标准

- 恰好交付四张有效的 1024×1024 PNG，并按 2×2 矩阵清楚标注。
- 四张均为明确的 2D 卡通，不出现明显毛绒、塑料、软陶或写实 3D 渲染质感。
- 四张的角色头身比例、身体轮廓、配色、耳机和脚部结构保持一致。
- 四张均使用低饱和深藏青蓝与暖奶油色的大色块配色，身体不能发浅或发灰白，脸颊和身体不存在条纹、斑点或猫科花纹。
- 四张的身体保持稳定正面坐姿，头部和耳机统一向画面右侧歪约 12°–15°。
- 四张的耳罩均为中等尺寸深靛蓝椭圆结构，随歪头形成自然高低和轻微远近差；单层细光边、连续斜头梁和尖耳均清楚，主要发光轮廓不被手爪遮挡。
- 01 与 03 的手臂、手腕和双爪顺着腹部圆弧自然放松，左右略有生活化差异且没有用力抓握；02 与 04 的右侧手爪轻扶低侧耳罩，另一爪继续自然放在腹部。
- 每张都显示两只完整尖耳、两只手爪、两条腿、两只完整脚和一副连贯耳机。
- 每只手和每只脚均有三枚可辨认的小爪尖；不得出现额外、缺失、合并或畸形爪子。
- 无文字、无水印、无额外角色、无复杂场景、无裁切肢体、无畸形耳机。
- HTML 对比页只展示这四张新稿，用户选定后再进入最终图标制作。
