# 卡比兽发光耳机应用图标预览设计

## 目标

生成一组六张 1024×1024 方形 PNG 预览，用于比较全身构图与视觉方向；本轮不替换 Heni 现有图标，也不制作 Windows、Android、iOS 或 macOS 的正式尺寸。

## 共同视觉约束

- 主体采用正面慵懒坐姿，完整身体位于画面中心，占画面约 78%–82%。
- 双腿自然向左右下方伸开，完整露出双脚、三枚小爪和暖棕色脚垫；腿部放松但保持左右视觉平衡。
- 双手自然、松弛地搭在大肚皮上，左右各一只，不遮住奶油色腹部的主体面积。
- 角色闭眼并带轻微满足表情；两只短尖耳完整露出，不能被头梁、头发状轮廓或画面裁切遮挡。
- 以用户提供的四张图片提炼角色外形特征：深蓝绿色身体、奶油色脸腹、极圆胖比例、短耳和慵懒神态。生成时使用文字化特征，不直接传入动画截图。
- 佩戴完整可辨认的头戴式耳机；耳罩和头梁局部发出青蓝到紫色的柔和霓虹光。
- 头梁在耳朵后方或上方形成清晰弧线；耳罩贴合头部两侧，但不能让角色耳朵消失。
- 深色背景，轮廓与背景保持足够对比；头梁、耳朵、双手和双脚四周均保留应用图标安全留白。
- 无文字、无水印、无其他角色、无复杂场景、无裁断的耳朵、耳机、双手或双脚。
- 即使缩小到 64×64，仍应一眼识别圆胖睡眠系角色、完整全身姿势、耳机和发光效果。

## 六个预览方向

1. **柔软毛绒 3D（推荐）**：柔软玩具般的短绒材质，身体与腹部有轻微压痕，青蓝—紫色光柔和照亮脸颊、双手和脚掌。
2. **圆润电影感 3D**：表面更光滑、体积光更明确，耳机结构精致，整体接近高完成度应用图标。
3. **复古水粉插画**：手绘不透明色块、轻微纸张颗粒和柔软墨线，强调怀旧、温暖与松弛感。
4. **夜色平面海报**：简化为大色块和干净轮廓，减少材质细节，以完整坐姿和发光耳机形成强烈图形识别。
5. **极简亮面图标**：光滑渐变、清晰圆形轮廓和有限细节，重点验证小尺寸下全身、耳朵和耳机是否仍清楚。
6. **软陶夜灯质感**：哑光软陶造型配柔和扩散光，耳罩像小夜灯一样发亮，气质最治愈、最可爱。

## 验收标准

- 六张图的风格差异明显，但主题、完整坐姿和角色特征一致。
- 每张图都完整显示两只耳朵、两只手、两条腿、两只脚和整副头戴式耳机。
- 双腿自然伸开，双手松弛搭在腹部，闭眼表情清楚，不能出现奔跑、站立或抱膝姿势。
- 耳机结构完整，发光区域明确且不过曝。
- 没有文字、水印、额外肢体、缺失肢体、畸形耳机或杂乱背景。
- 本轮交付仅为视觉预览；用户选定方向后再迭代最终版及平台图标。
