# 卡比兽发光耳机应用图标预览设计

## 目标

生成一组三张 1024×1024 方形 PNG 预览，用于比较视觉方向；本轮不替换 Heni 现有图标，也不制作 Windows、Android、iOS 或 macOS 的正式尺寸。

## 共同视觉约束

- 主体为卡比兽正面或轻微三分之二视角的头肩/半身构图，位于画面中心。
- 以用户提供的四张图片作为角色外形参考：深蓝绿色身体、奶油色脸腹、圆胖比例、短耳和慵懒神态。
- 佩戴完整可辨认的头戴式耳机；耳罩和头梁局部发出青蓝到紫色的柔和霓虹光。
- 深色背景，轮廓与背景保持足够对比；主体四周保留应用图标安全留白。
- 无文字、无水印、无其他角色、无复杂场景、无裁断的耳朵或耳机。
- 即使缩小到 64×64，仍应一眼识别卡比兽、耳机和发光效果。

## 三个预览方向

1. **圆润 3D 徽章（推荐）**：柔软玩具般的 3D 质感，深夜蓝黑渐变背景，青蓝—紫色耳机光晕。完成度最高，适合 Heni 的沉浸式播放器气质。
2. **复古动画**：参考旧版动画的赛璐璐平涂与轻微纸张颗粒，表情更慵懒，耳机霓虹光保持现代感。
3. **极简亮面图标**：减少毛发和材质细节，强调圆形轮廓、脸部和大耳罩，采用现代应用图标的光滑渐变与强对比。

## 参考图片角色

- `stage1.jpg`：脸部、腹部颜色与正面比例参考。
- `stage2.jpg`、`stage3.jpg`：整体圆胖体型与放松神态参考。
- `1701531240185.jpg`：远距离轮廓和小尺寸识别参考。

参考图只用于角色外形与气质，不复刻其中的动作、构图或森林背景。

## 验收标准

- 三张图的风格差异明显，但主题和角色特征一致。
- 耳机结构完整，发光区域明确且不过曝。
- 没有文字、水印、额外肢体、畸形耳机或杂乱背景。
- 本轮交付仅为视觉预览；用户选定方向后再迭代最终版及平台图标。
