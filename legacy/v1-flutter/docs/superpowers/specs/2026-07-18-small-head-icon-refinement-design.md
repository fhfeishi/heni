# 小头身比例高质量图标预览修订设计

## 目标

在上一轮六张预览的基础上重新生成三张高质量预览，用于确认更自然的小头身比例。本轮仍不制作或替换任何平台的正式应用图标。

## 范围

- 仅生成三张 1024×1024 方形 PNG，不再以数量为优先。
- 三个方向分别为：柔软毛绒 3D、圆润电影感 3D、软陶夜灯。
- 三张图都从头生成，不对旧图做几何缩放或局部拉伸，以避免脸部、耳机和材质细节进一步劣化。
- 新文件使用独立的 `v2` 输出目录和文件名，不覆盖上一轮六张预览。

## 比例修订

- 头部、奶油色脸块、两只耳朵和整副头戴式耳机作为一个视觉整体，比上一轮缩小约 15%。
- 头部约占完整角色高度的 30%–34%；不能继续使用接近大头娃娃的比例。
- 圆胖身体和奶油色大肚皮成为画面主体；腹部、双手、双腿和双脚保持厚实、舒展、可爱。
- 缩头后重新构建颈肩衔接、耳机弧线和脸部结构，不能出现简单贴图缩放造成的断层或空洞。
- 角色整体继续占画面约 78%–82%，头顶留白略增加，但身体不能因此被裁切或压缩。

## 共同视觉约束

- 正面慵懒坐姿，双腿自然伸向左右下方，双脚完整露出。
- 双手分别自然搭在大肚皮上，不能合并、缺失或遮挡主要腹部区域。
- 双眼闭合，神态安静满足；两只圆润耳朵完整可见。
- 一副结构连贯的头戴式耳机，耳罩与头梁发出受控的青蓝至紫色柔光。
- 身体为暗青绿色，脸部与腹部为暖奶油色；圆形趾豆和蓝紫色脚垫保持清楚。
- 深色简洁背景，保留应用图标安全留白。
- 无文字、无水印、无额外角色、无复杂场景、无额外或缺失肢体、无变形耳机。

## 三个精修方向

1. **柔软毛绒 3D**：短绒材质细腻可见，腹部有自然压痕，耳机柔光轻微照亮脸颊、手掌与脚掌。
2. **圆润电影感 3D**：光滑高级表面、准确的耳机结构和克制体积光，优先呈现完成度最高的应用图标感。
3. **软陶夜灯**：哑光软陶与轻微手作圆润感，耳罩像小夜灯一样发光，但不牺牲轮廓和五官清晰度。

## 质量策略

- 使用内置图像生成模式，每个方向单独生成，提示词共享严格的比例与姿势约束。
- 每张生成后分别检查头身比例、五官、耳朵、耳机、手脚、材质和小尺寸识别。
- 仅当某张未满足验收标准时，针对单一问题重新生成；不以增加大量候选来掩盖质量问题。
- HTML 对比页只展示这三张新稿，便于集中比较比例、质感与耳机光效。

## 验收标准

- 最终交付恰好三张新预览，每张均为有效的 1024×1024 PNG。
- 头部比上一轮视觉上缩小约 15%，身体和大肚皮明显成为主体。
- 耳机大小与新头部匹配，没有压头、悬空或过大的感觉。
- 两只耳朵、两只手、两条腿和两只脚均完整、自然且可辨认。
- 材质细节、边缘、灯光与颜色干净，没有明显糊化、塑料感失控或过曝。
- 三个方向差异明确，但角色姿势、比例和共同配色保持一致。
- 本轮仅用于选择精修方向；用户选定后再制作最终应用图标。
